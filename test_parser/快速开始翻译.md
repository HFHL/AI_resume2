# 🌐 简历翻译功能 - 快速开始

## 第一步：启动翻译服务器

### Windows 系统
双击运行：
```
test_parser/start_translation_server.bat
```

### Mac/Linux 系统
```bash
cd test_parser
python translation_server.py
```

服务器启动后会显示：
```
🚀 启动翻译服务器...
📡 监听地址: http://localhost:5001
* Running on http://0.0.0.0:5001
```

> **注意**: 保持这个窗口打开！关闭会停止服务器。

---

## 第二步：打开测试查看器

在浏览器中打开：
```
test_parser/viewer.html
```

---

## 第三步：筛选需要翻译的文件

1. 在页面顶部，选择筛选器：**⚠️ 需要翻译**
2. 左侧列表会显示所有需要翻译的文件（带有 ⚠️ 标记）
3. 右上角会显示统计：`(X/总数)`

---

## 第四步：翻译文件

1. 点击左侧列表中任意文件
2. 在 Markdown 卡片中，会看到：
   - 标题显示：**Markdown (未翻译)**
   - 绿色按钮：**🌐 翻译为中文**
   - 提示文字：**👈 点击翻译按钮生成中文版**
3. 点击 **🌐 翻译为中文** 按钮
4. 等待翻译完成（约20-60秒）
5. 翻译完成后：
   - 自动显示中文版本
   - 标题变为：**Markdown (中文版)** ✅
   - 翻译按钮消失

---

## 功能说明

### 智能状态显示

- **⚠️ (未翻译)** - 橙色标记，显示翻译按钮
- **✅ (中文版)** - 绿色标记，显示译文
- **(英文版)** - 蓝色标记，显示原文

### 切换原文/译文

点击 **Toggle Original/Translated** 按钮，可以在原文和译文之间切换查看。

### 文件列表状态图标

- **⚠️** - 需要翻译的文件
- **✅** - 已翻译的文件
- 无图标 - 没有 Markdown 文件

### 筛选选项

- **All** - 显示所有文件
- **⚠️ 需要翻译** - 只显示有原文但没有译文的文件
- **No JSON** - 没有解析结果的文件
- **No OCR MD** - 没有 OCR 输出的文件
- **Has Translated MD** - 已有中文译文的文件

## 常见问题

### ❌ 翻译按钮点击后没反应？

**原因**：翻译服务器未启动

**解决**：
1. 检查是否运行了 `translation_server.py`
2. 查看服务器窗口是否有错误信息
3. 确认端口 5001 没有被占用

### ❌ 提示 "翻译服务器未运行"？

**解决**：
```bash
# Windows
test_parser\start_translation_server.bat

# Mac/Linux
cd test_parser
python translation_server.py
```

### ❌ 翻译失败？

**可能原因**：
1. OPENAI_API_KEY 未配置
2. 网络连接问题
3. API 配额不足

**检查**：
1. 查看服务器窗口的错误日志
2. 确认环境变量已配置：
   ```bash
   echo %OPENAI_API_KEY%  # Windows
   echo $OPENAI_API_KEY   # Mac/Linux
   ```

### 🐌 翻译很慢？

这是正常的！翻译器会：
1. 按照 `#` 标题分段
2. 逐段调用 LLM 翻译
3. 一个简历通常需要 20-60 秒

可以在服务器窗口看到实时进度。

## 批量翻译

如果有很多文件需要翻译，可以使用命令行批量翻译：

```bash
# 翻译整个目录
python test_parser/translate_md.py test_parser/ocr_outputs/

# 会自动跳过已翻译的文件
```

## 技术细节

### 翻译策略
- 按 `#` 标题分段，保持上下文连贯
- 保留专有名词（公司名、产品名、技术术语）
- 保留 Markdown 格式
- 保留数字和符号

### 使用的模型
- 默认：`gpt-4o-mini`（性价比高）
- 可选：`gpt-4`（质量更高，成本更高）

### API 端点
- `GET /health` - 检查服务器状态
- `POST /translate` - 翻译文本
- `POST /translate_file` - 翻译文件
