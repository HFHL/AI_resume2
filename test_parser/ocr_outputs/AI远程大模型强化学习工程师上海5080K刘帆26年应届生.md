# 科研成果

1. THOR：面向商业数据库的 Text-to-SQL 自愈多智能体系统 第一作者 EMNLP

核心算法与创新：自愈能力设计： 提出并实现了一个具备“自愈能力”的多智能体系统。核心设计了包含自我修正(Self-Correction与评分(Rating)的闭环执行工作流。该机制能够自动识别并修复SQL 语法错误、空返回，并处理单位换算、模糊匹配等深层语义歧义

多智能体协作： 设计了以 Supervisor Agent 为核心的任务分发与调度机制，协同多个功能Agent 完成从自然语言理解到 SQL 生成、执行及结果解释的全过程，显著提升了复杂查询的成功率。

成果： 成功将前沿的 Text-to-SQL 技术转化为可直接赋能业务人员、安全可靠的自动化数据分析工具

2. DEREK：面向企业级应用的增强检索生成(RAG)优化框架 第一作者 EMNLP

核心算法与创新：混合检索与重排： 提出并实现了一套创新的混合检索 (HNSW+BM25) 与重排 (Re-ranking) 策略。该策略有效融合了向量语义与关键词匹配的优势，显著提升了复杂文档问答的精准度与可靠性。

数据溯源与验证循环： 首次在 RAG 系统中引入基于 LangGraph 的验证循环机制，通过算法强制要求模型生成的每一句内容都必须有源可溯，若无依据则触发重生成。

量化成果：

在 LegalBench数据集上，该框架将检索精准度 $( \mathsf { P } @ 1 0 )$ )提升了7 个百分点，召回率 $\angle R @ 5 0$ )提升了1 个百分点。  
在 TRACe 基准测试中，所研发管线的事实一致性相比传统 FAISS方案提升了 $23 \%$ 。  
成功将无依据陈述的比例严格控制在 $3 \%$ 以内，为 RAG 在法律、金融等高合规领域的应用提供了坚实的技术基础。
