# 具体方案：

# 1.数据构建与标注

收集2000+电商/广告海报，由专业设计师标注布局、文案、色彩偏好。设计标注体系：布局合理性、视觉焦点分布、信息层级。文案渲染、关键词突出以及安全合规性，比如品牌LOGO误用。

# 2.奖励模型训练

基于BLIP架构构建多模态评估模型，通过结合CLIP语义对齐以及人工美学评分

# 3.ReFL优化算法

梯度反馈机制：基于SD XL在扩散模型去噪后期（第15\~20步）注入奖励信号，直接优化生成方向。  
动态权重调整：文案相关性权重随去噪步数递增，避免早期过度约束。

# 4.SimPO 优化prompt生成

语义相似性优化：利用SimPO微调Qwen 7B自动改写prompt，提升生成精准度。  
风格适配：根据品牌调性调整Prompt，确保生成内容符合业务要求。
