# 基于回归的监督学习用于预测薄壁风塔截面焊缝凹陷轮廓

2022.09-2022.12

研究背景与意义

风电塔筒是利用可再生能源的重要结构，但焊接处存在的几何缺陷——\*\*焊缝凹陷（weld depression）\*\*会影响其结构强度和稳定性。论文目标是通过回归模型预测这种焊缝凹陷的形状，为设计和制造阶段提供数据支持，从而提升塔筒的可靠性和可持续性。

 

# 数据与处理

• 使用三维激光扫描获取三个缩小比例（1/4）的风电塔截面数据（共12条焊缝，6000个数据点）。  
• 焊缝凹陷的定义是：实际圆柱与理想圆柱在焊缝处的半径偏差。  
• 对每个焊缝截取中心 $\pm 2 5 0 \mathrm { m m }$ 范围的数据，剔除焊珠干扰区域。

 

建模方法

论文设计并比较了三个监督学习模型来拟合焊缝凹陷剖面：

# 1. 最大似然估计（MLE）模型

• 基于Rotter Teng (RT) 理论模型。  
• 使用梯度下降法拟合参数 w_0, \lambda, \sigma。  
• 能较好拟合数据，但误差较大。  
2. 多项式回归（Polynomial Regression）• 将输入变量 d 转换为不同阶数（2\~15）的多项式特征。  
• 最终选择阶数为8的模型作为最优。  
• 表现良好，易于实现。  
3. 神经网络模型（Neural Network）• 两层隐藏层、每层1000个神经元，ReLU 激活函数。  
• 使用均方误差作为损失函数，训练10次取平均结果。  
• 表现最优，泛化能力强。

 

评估方法

使用四种评估指标对模型进行训练集与测试集性能评估：

• MSE（均方误差） • R²（拟合优度） • Pearson’s 相关系数 • Kendall’s Tau

结论是：神经网络模型在预测风电塔焊缝凹陷方面表现最佳，具有更强的泛化能力，适合实际应用。
