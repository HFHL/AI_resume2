# AI加密货币助手 负责人

这是一个辅助炒币的工具，核心功能包括：

1. 加密货币相关知识问答；  
2. 预测加密货币未来7天的行情走势；  
3. 自动代理用户买卖加密货币；  
该项目是基于LangGraph框架开发的Multi Agent(多角色智能体)，采用PlanExecute模式，相较于ReAct步骤更清晰且同步执行多个工具。关键模块分为以下几个：  
1. 市场情报模块：负责收集、整理、总结和分析市场信息，包括新闻、价格、twitter。情报用来评估市场情绪并总结趋势，除了最新情报，历史中导致价格变化的重要事件也会生成摘要，总结后用于辅助交易决策。  
2. 市场反思模块：分析市场情报与过去未来价格变化之间的关系，针对不同时间范围生成详细的价格曲线分析，重点是学习价格变化的潜在模式，并从市场情报摘要和价格变动中得出导致价格变动的原因，生成经验教训的文本以便后续决策参考。3. 历史决策反思模块： 分析和反思过去的交易决策，通过回报率、夏普比率等指标评估每个交易决策的正确性，针对成功或失败提出改进或纠正，该模块可以看作是一个动态知识库，随着做出每个决策而发展，应用学到的经验教训做出更明智的决策。  
4. 记忆模块：为上述3个模块提供存储和检索功能，存储各模块的分析和总结，提升决策能力。  
5. 决策模块： 整合市场情报、价格曲线分析、过去决策的反思等关键信息，综合所有的分析结果做出最终决策(买入、卖出、持有)，利用思维链COT和上下文学习，不仅执行交易还可以提供推理，确保每个决策都有相关依据。

# AI搜索 $\mathbf { \nabla } + \mathsf { \pmb { A } } \mathbf { l }$ 算命 负责人

2023.12-2024.12

AI搜索使用LangChain开发，主要流程分为：

1.查询优化、扩展、上下文依赖：将用户的原始问题重写生成更专业更严谨的问题。然后生成更多角度的子问题，这也就加大了搜索范围，便于检索出更多优质内容。如果是连续追问，则会结合上下文生成带总结的问题。同时会根据用户过往的搜索记录，为用户添加更多个性化的上下文。  
2.使用上一步生成的问题和子问题，调用搜索引擎API搜索内容，再通过LLM进一步筛选出适合回答该问题的搜索内容，通常是5个。  
3.开始进行数据处理，检查可访问性 $>$ 获取 html $>$ 生成 Documents $>$ format 格式化。  
4.开始重排和去重，按照相似度对文档排序，相似度高的排在最前和最后，因为上下文在prompts的开头和结尾处时大模型推理的效果更好。如果两个文档过于相似，则只保留其中一个，减少上下文长度。  
5. 通过搜索召回的上下文 context和用户输入的chat_history question一起进入response synthesizer chain工作流，最终生成搜索响应。  
6. 为了满足实时性要求，用到了缓存技术，相似的问题不会重复推理。  
7. 在另一个进程中定时对用户的问题和答案进行分析，在其中找出用户的喜好，方便下次提问时加入个性化内容。

AI算命使用LangChain开发，以聊天的形式呈现给用户，底层是Agent。在算命的细分场景下做了专业知识库增强，Agent拥有八字算命、周公解梦、摇卦等能力。Agent能自主决策工具调用，使用OpenAI的Tool Calling功能实现。还拥有持久化的记忆系统。

# AI输入法 负责人

在一段关系开始的时候，最难的通常是破冰阶段，用户普遍反馈不知道如何找话题、如何回复。针对这种情况，我们开发了一款交友聊天辅助工具《AI输入法》，工具以手机输入法的形态呈现，用户能够一键生成回复。项目使用LangChain开发，底层实现采用了提示词工程 $^ +$ RAG，向量数据库中保存了大量对话案例。

1.检索：使用查询扩展、MMR、BM25检索出相关对话案例。  
2.去重：将多个结果按相似度比较，如果超过阈值则只保留一个。  
3.重排：按上一步记录的相似度做排序，将相似度高的内容放在头部和尾部，从而获得更好的推理结果。  
4.压缩：删除不重要的标记和token，只保留相关上下文。  
5.使用不同的提示词打造不同的人设，最后提交给大模型生成最终回复。
