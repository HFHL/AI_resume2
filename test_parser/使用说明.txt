           简历测试与翻译系统 - 快速使用指南
═══════════════════════════════════════════════════════════

【方式一：一键启动（推荐）】
──────────────────────────────────────────────────────

双击运行：启动完整测试环境.bat

这会自动：
  ✅ 启动查看器服务器 (端口 8000)
  ✅ 启动翻译服务器   (端口 5001)
  ✅ 自动打开浏览器


【方式二：手动启动】
──────────────────────────────────────────────────────

步骤 1：启动查看器服务器
  双击运行：start_viewer.bat
  或命令行：cd test_parser && python -m http.server 8000

步骤 2：启动翻译服务器
  双击运行：start_translation_server.bat
  或命令行：cd test_parser && python translation_server.py

步骤 3：打开浏览器
  访问：http://localhost:8000/viewer.html


【使用流程】
──────────────────────────────────────────────────────

1. 服务器启动后，浏览器会自动打开 viewer.html

2. 在筛选器中选择：⚠️ 需要翻译

3. 点击左侧列表中的文件

4. 如果看到 "🌐 翻译为中文" 按钮，点击它

5. 等待翻译完成（20-60秒）

6. 自动显示中文翻译版本


【端口说明】
──────────────────────────────────────────────────────

端口 8000：查看器服务器
  - 提供 viewer.html 页面访问
  - 显示 PDF、Markdown、解析结果

端口 5001：翻译服务器
  - 提供翻译 API 服务
  - 接收翻译请求并返回结果


【注意事项】
──────────────────────────────────────────────────────

⚠️ 确保配置了环境变量：
   OPENAI_API_KEY=你的密钥

⚠️ 如果端口被占用，会启动失败
   - 关闭占用端口的程序
   - 或修改脚本中的端口号

⚠️ 翻译需要时间，请耐心等待
   - 不要关闭服务器窗口
   - 不要重复点击翻译按钮


【快捷键】
──────────────────────────────────────────────────────

Ctrl+C    停止服务器
F5        刷新页面


【文件位置】
──────────────────────────────────────────────────────

原始简历：     test_inputs/
OCR 输出：     ocr_outputs/
翻译输出：     ocr_outputs_zh/
解析结果：     test_outputs/


【常见问题】
──────────────────────────────────────────────────────

Q: 翻译按钮点击没反应？
A: 检查翻译服务器是否启动（端口5001）

Q: 页面打不开？
A: 检查查看器服务器是否启动（端口8000）

Q: 翻译失败？
A: 检查 OPENAI_API_KEY 是否配置正确
